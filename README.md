# Run-Game

## Overview
Run-Game is an endless runner style game developed in Unity, where the player controls a character running continuously while avoiding obstacles. The game challenges players' reflexes and timing to achieve the highest possible score.

## Features
- Simple and intuitive controls for jumping, sliding, or moving sideways.
- Variety of obstacles to avoid.
- Scoring system based on distance run and obstacles avoided.
- Visual effects created using ShaderLab shaders.
- Sound effects and background music to enhance gameplay experience.
- Responsive UI including start screen, in-game HUD, and game over screen.

## Development
- **Engine:** Unity 3D
- **Languages:** C#, ShaderLab
- **Platform:** PC, Web, Mobile (supports keyboard and touchscreen input)
- **Project Structure:**
  - **Assets:** Contains sprites, models, shaders, audio files.
  - **Scripts:** Game logic in C# scripts managing player controls, obstacle spawning, and game state.
  - **ProjectSettings:** Unity configuration files.

## How to Run
1. Clone or download the repository.
2. Open the project folder in Unity Editor.
3. Open the main scene located in the `Scenes` folder.
4. Press Play to start the game.
